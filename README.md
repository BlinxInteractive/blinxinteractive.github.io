# blinxinteractive.github.io

The Blinx Interactive website, served by GitHub Pages at https://blinxinteractive.github.io/.

- `index.html`: home page
- `pawventure/privacy.html`: Pawventure privacy policy (the store listings link here). Its source is `docs/privacy.html` in the game repo; copy changes across.
- `app-ads.txt`: authorised ad sellers for AdMob. It must stay at the site root, on the domain given as the developer website in the store listings.
